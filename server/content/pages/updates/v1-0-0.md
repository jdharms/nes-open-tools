Initial release!

* Randomized 18-hole courses using holes from *NES Open Tournament Golf*
and *Mario Open Golf*.
* Seeded wind values ensure all players face the same wind conditions on each shot.
* Players can submit their scorecard via QR code scan at the end of the round.
* Players are "mercy-ruled" on each hole after their 9th stroke.
* Course music is a random course theme from either game.
* "Course Signpost" art by spaces90.
